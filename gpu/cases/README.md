# DeepSeek-V4.1 DrPerf GPU cases

Runnable CPU-only translated-PTX cases, byte-pinned to the study toolchain. DrPerf fits resource interfaces; elapsed times below come only from separately identified H100 receipts. **FOUND** means DrPerf first identified the issue; **EXPLAINED** means it explained a timing symptom structurally; **QUANTIFIED** means another tool found it and DrPerf supplied counts; **POTENTIAL/BLOCKED** means no fix or an explicit coverage limit. Proposed cases are not numerical passes.

Run `python3 run_all.py --jobs 2`; each fixture executes from its own directory. Per-case `results/verification.json` records status, exact commands and interface checks. Workspace category/accounting wrapper: `/home/ubuntu/gen-deepseek41/tools/verify_drperf_cases.py`. No H100 allocation is requested by these scripts.
